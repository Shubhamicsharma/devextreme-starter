## Local Development with HTTPS

This project is configured to use HTTPS for local development with self-signed certificates generated by `mkcert`. This ensures a secure and consistent development environment without browser warnings.

### One-Time Setup

1.  **Install `mkcert`**

    -   **Windows (with Chocolatey):**
        ```bash
        choco install mkcert
        ```
    -   **macOS (with Homebrew):**
        ```bash
        brew install mkcert
        ```
    -   **Linux (Debian/Ubuntu):**
        ```bash
        sudo apt install libnss3-tools
        mkcert -install
        ```

2.  **Install Local Certificate Authority**

    Run the following command once to create and install a local Certificate Authority (CA) in your system's trust stores. This is what prevents browser warnings.

    ```bash
    mkcert -install
    ```

### Certificate Generation

1.  **Navigate to the Project Root**

    All commands should be run from the root of this project directory.

2.  **Generate Certificates**

    Run the following command to generate a certificate for `localhost`, `127.0.0.1`, and the IPv6 loopback address `::1`.

    ```bash
    mkcert localhost 127.0.0.1 ::1
    ```

    This will create two files in the project root:

    -   `localhost+2.pem` (the certificate)
    -   `localhost+2-key.pem` (the private key)

3.  **Move and Rename Certificates**

    Move the generated files into the `/certs` directory and rename them as follows:

    -   Rename `localhost+2.pem` to `localhost.pem`
    -   Rename `localhost+2-key.pem` to `localhost-key.pem`

    The `/certs` directory is intentionally ignored by Git, so your local certificates will not be committed to the repository.

### Running the Application

Once the setup is complete, you can start the Angular development server as usual:

```bash
npm start
```

The application will now be served at **https://localhost:4200** without any browser security warnings.
